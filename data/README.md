# 台語用語資料維護說明（data/taigi.json）

台語貼圖專區的所有用語都放在 `taigi.json`。**新增或修正用語只要改這個檔案，不必修改程式碼。**

## 一句用語的欄位

```json
{
  "id": "t130",
  "cat": "c14",
  "hanji": "毋通",
  "zh": "不行；不可以",
  "check": "headword",
  "pun": "母湯",
  "mix": "這樣毋通啦",
  "tl": "m̄-thang"
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id` | ✅ | 唯一代號，新增時接續最後一號（t152、t153…），**不要重複使用舊號**（收藏靠它辨認） |
| `cat` | ✅ | 情境分類代號，對應 `categories` 的 `id` |
| `hanji` | ✅ | **台語正字**：依教育部推薦用字 |
| `zh` | ✅ | 華語意思；多個意思用「；」分隔，App 顯示第一個 |
| `pun` | 選填 | **趣味諧音**：網路常見寫法。沒有常見寫法就不要填，App 會自動顯示正字並註明 |
| `mix` | 選填 | 台華混搭版本 |
| `tl` | 選填 | 臺羅拼音。只在有辭典來源時填寫，不要自行猜測聲調 |
| `check` | ✅ | 查核層級（見下表） |
| `note` | 選填 | 補充說明，會顯示在用語詳細資訊 |

### 查核層級 `check`

| 值 | 意思 |
|---|---|
| `headword` | 整句就是辭典詞目或俗諺條目 |
| `example` | 整句出現在辭典例句中 |
| `words` | 每個詞都是辭典詞目，整句是常用口語組合 |
| `manual` | 含辭典未收的字詞，已人工確認（請在 `note` 說明理由） |

## 新增用語的流程（判斷規則）

1. 到 <https://sutian.moe.edu.tw/> 用**華語**查詢意思，確認台語詞目的寫法
2. `hanji` 只能填辭典寫法。例如「頭殼疼」不是「頭殼痛」、「天公疼戇人」不是「天公疼憨人」
3. 網路寫法（母湯、歐北來、揪甘心）只能放在 `pun`，**不可放進 `hanji`**
4. 避免使用 Unicode 擴充 B 區以後的罕用字（例如「𠢕」「𨑨」），很多手機缺字；必要時在 `note` 註明
5. 不收錄歌詞（例如流行歌的歌詞句子），避免著作權問題
6. 修改後更新最上方的 `version`、`updated`，並修改 `sw.js` 的 `VERSION`，使用者才會拿到新資料

## 常見誤區

- ❌ 把華語直接換成台語發音的同音字（例如「哩賀」寫進 `hanji`）
- ❌ 只因為網路很流行，就把諧音當成正字
- ❌ 自己拼臺羅聲調，造成錯誤讀音

## 企劃主題 `themes`

```json
{ "name": "台灣菜市場人生", "desc": "菜市場、小吃與夜市", "cats": ["c10"] }
```

`cats` 列出這個主題優先使用的情境；張數不夠時，App 會自動從其他情境補足，而且不重複。
