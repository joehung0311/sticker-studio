# 課堂作業專案簡介｜今天貼什麼？ Sticker Studio

## App 名稱
**今天貼什麼？**（Sticker Studio）v1.0.0・品牌：白話實驗室 baihua
標語：生活有百種心情，貼圖不必只有一種。

## 開發動機
聊天時常常找不到「剛好」的貼圖；想用自己或毛孩當貼圖，卻不會畫畫、不懂設計，也不知道怎麼跟 AI 描述才畫得好。

## 解決的生活問題
1. **不會描述**：把「角色、畫風、表情、文字」整理成完整的 AI 生圖提示詞
2. **沒有靈感**：生活用語庫 64 句＋貼圖盲盒隨機組合
3. **生完圖還要加工**：瀏覽器內直接裁切、加中文字、去背、切宮格、調成 LINE 尺寸
4. **怕資料外流**：照片只在自己的瀏覽器處理

## 主要功能
照片變貼圖、創造新角色、8 種畫風、生活用語庫、貼圖盲盒、整套貼圖企劃（1～40 張）、AI 生圖助手、貼圖加工室、LINE 貼圖工具箱、我的貼圖收藏。

## AI 如何參與創作流程
```
人：決定角色與心情 → App：整理成結構化提示詞 → AI（ChatGPT／Gemini）：生成圖片
→ App：裁切、加字、去背、切圖、檢查規格 → 人：挑選、下載、分享
```
App 負責「把想法說清楚」和「把成品做完整」，AI 負責「畫」，人負責「判斷」。

**判斷規則（為什麼這樣分工）**
- AI 生圖常把中文字畫錯 → 提供「之後在加工室加字」選項，用電腦字型保證正確
- AI 不一定能輸出透明背景 → 提示詞要求退回純白背景，再用單色去背
- 同一套貼圖角色容易走樣 → 儲存角色設定＋提示詞加入一致性要求＋宮格一次生成

**常見誤區**
- 「單色去背」不等於 AI 智慧去背：只能移除相近的單一顏色
- 企劃的 1、4 張是自用張數；LINE 上架只接受 8／16／24／32／40 張
- 工具檢查通過 ≠ LINE 審核通過

## 使用的技術
HTML、CSS、JavaScript（無框架）、HTML Canvas、IndexedDB、LocalStorage、PWA（Manifest＋Service Worker）、JSZip、qrcode-generator、GitHub Pages、Playwright 自動化測試。

## 不需要 API Key 的設計方式
直接生圖需要付費 API 與金鑰，金鑰放在公開網站前端一定會外洩。V1.0 改成「產生提示詞＋開啟使用者自己的 ChatGPT／Gemini」，所以 App 本身沒有任何金鑰、不需要後端、可以免費公開分享。

## 個人資料及照片隱私保護
- 沒有伺服器、沒有帳號、沒有追蹤
- 照片以 Canvas 在本機處理，不上傳（自動化測試已驗證無上傳請求）
- 收藏只存在使用者自己的瀏覽器，不同使用者互不相通

# 操作展示流程（約 2～3 分鐘）

| 時間 | 步驟 | 要講的重點 |
|------|------|------------|
| 0:00 | 用手機掃 QR Code 或開網址 | 不用註冊、不用 API Key |
| 0:15 | 進「🎨 創造新角色」，選「貓咪」、畫風「可愛 Q 版」 | 8 種畫風都有示意圖 |
| 0:35 | 按「💬 挑用語」選「下班啦」（或到「🎁 貼圖盲盒」抽一次） | 64 句生活用語、可鎖定再抽 |
| 0:55 | 按「複製並開啟 ChatGPT」 | 提示詞已包含構圖、留白、透明背景、原創提醒 |
| 1:15 | 匯入事先準備好的 AI 圖片到「✂️ 貼圖加工室」 | 現場生圖可能要等，先備好圖 |
| 1:30 | 裁切成 LINE 370×320、加字「下班啦」、單色去背 | 中文字由 App 加，保證正確 |
| 1:55 | 下載 PNG／存到收藏 | 圖片只在本機處理 |
| 2:10 | （加碼）到「📱 LINE 工具」匯入九宮格，切成 9 張＋ZIP | 自動產生主圖與標籤圖 |
| 2:30 | 回首頁「🔗 分享給朋友」秀 QR Code | 同學可以馬上用 |

**展示前準備**：一張 AI 生成的單張貼圖、一張 3×3 宮格圖；手機先「加入主畫面」；預先開好 ChatGPT 並登入。
