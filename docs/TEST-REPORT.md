### v1.2 開發中發現並修正
| 問題 | 原因 | 修正 |
|---|---|---|
| 開源字型讓整個網站變成超粗體 | 內建的思源黑體與網頁本身指定的字型同名 | 內建字型一律改用 `SS ` 開頭的專屬名稱 |
| 第一次開網站，歡迎視窗一閃即逝 | Service Worker 首次接管時觸發自動重新整理 | 只在「從舊版更新」時重新整理 |
| 放大檢視時畫布跑到畫面外 | 切換分頁後頁面捲動 | 放大時自動把畫布捲回可視範圍 |
| 「𪜶」在粗體與系統黑體顯示成方塊 | 思源黑體與部分系統字型沒有此字 | 缺字時改用粉圓備援 |
| 裝飾放滿時新增裝飾出錯 | 找不到空位時回傳空值 | 一定回傳可用位置 |
| 鎖定位置後仍被移動 | 字變大時被推回邊界內 | 鎖定位置時改為縮小字級 |

### v1.2 限制（不標示為已完成）
- 消除工具為**手動**，不是 AI 智慧修復；「周圍延伸填補」對複雜圖案效果有限
- 沒有使用瀏覽器端 AI 影像修復模型（評估後：模型檔動輒數十 MB，手機載入與執行負擔過大，暫不加入）
- 未內建金門話專屬用語庫；金門話可輸入與顯示
- 韓文使用裝置系統字型；直排時標點不自動轉向
- 手機觸控以 Chrome 模擬與 CDP 觸控事件驗證，尚需實機確認

### 台語用字查核方式（事實）
- 以 g0v/moedict-data-twblg（教育部臺灣閩南語常用詞辭典開放資料，14,489 筆詞目）逐條比對
- 結果：辭典詞目 40 句、辭典例句 7 句、逐詞查核 103 句、人工確認 1 句（「臺灣上讚」：「臺」為推薦用字，開放資料未單獨收錄）
- 限制：比對資料是舊版《臺灣閩南語常用詞辭典》，現行網站為修訂版《臺灣台語常用詞辭典》。「逐詞查核」代表每個詞都在辭典中，**不代表整句是辭典收錄的句子**
- 趣味諧音與台華混搭是本專案整理的常見寫法，沒有官方標準，因此不做辭典比對

## 二、開發中發現並已修正的問題
| 問題 | 原因 | 修正 |
|---|---|---|
| 從其他頁回到「整套企劃」再匯出，下載到空白企劃 | 換頁時舊頁面的事件監聽留在共用容器上 | 路由每次換頁改用全新容器（`js/app.js`） |
| 台語專區無法開啟 | `taigi.js` 比頁面登記表先載入 | 兩邊都改為「已存在就沿用」 |
| 從專區帶字到加工室後選空白畫布，文字變回「早安」 | 空白畫布重設時讀取已清空的暫存 | 改為保留目前文字 |
| 宮格提示詞沒有說明台語句子的意思 | AI 不畫字時沒有附上華語意思 | 每格加上「台語，意思是…」 |
| 手機上「全部調整為 LINE 尺寸」偶爾清單數量錯誤 | 連點或檔案尚在讀取時，兩個處理同時執行 | 清單操作改為排隊執行，處理中按鈕停用；修正後連續 3 次完整測試全數通過 |
