## 四、已知限制（設計上的限制，非錯誤）
- App 不直接生成 AI 圖片（V1.0 規格）
- 單色去背不是 AI 智慧去背，複雜背景效果有限
- 加字字型使用裝置內建字型，不同裝置外觀略有差異
- LINE 工具只做初步檢查，不保證通過審核
- 收藏存在瀏覽器，清除資料會遺失（已提供備份）
